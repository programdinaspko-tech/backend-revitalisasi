⚠️ Perhatian Operator Sekolah:

Pengisian data kelengkapan sarana, infrastruktur TIK, GTK, dan siswa dilakukan secara akurat sesuai keadaan riil di sekolah Anda.

  • 1. Isi data profil dan infrastruktur TIK pada menu Data Sekolah.
  • 2. Input Luas Tanah terlebih dahulu sebelum menambah data Bangunan & Ruang.
  • 3. Setiap Ruang yang diinput WAJIB melengkapi data Sarana Alat di menu Alat.
  • 4. Lakukan Validasi Data untuk mengecek kelengkapan sebelum Sinkronisasi.
